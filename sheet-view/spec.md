# Sheet-View

Sheet-View is an app that let's people view chordpro and other chord sheets.

File Support:

- chord pro
- chords over words (regular chord sheets)
- Ultimate Guitar sheets

The viewer displays the sheet in Chord Pro format and allows the user to select alternative views like:
- Plain Text
- HTML
- Chords over words
- PDF

## Usage

From the main screen, drop a file into the "View" area or click "View" to select a file.
